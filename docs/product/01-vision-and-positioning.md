# 01 · Vision and positioning

## One-liner

**Read the NCERT page. Practise that same page.**

PageWise is a calm study workspace for NEET aspirants: the NCERT page on one side, exam-style questions written for that exact page on the other.

## Problem

NEET Biology is overwhelmingly decided by what is on the NCERT page. Yet students:

1. read a page, then go hunting for questions across apps and PDFs;
2. get a question wrong with no fast way back to the NCERT line it came from;
3. lose the link between a line and a question when notes, books and tests live in different places.

## Promise

Every question is tied to a source page. Practising and reading are one motion, not two tools.

## Target users

| Persona | Needs | Notes |
|---|---|---|
| **Aspirant (primary)**: Class 11/12 or dropper preparing for NEET UG | Retain NCERT Biology, practise in NEET style, track weak chapters | Mostly 16–20 years old. Many under 18 (privacy rules apply, see doc 03) |
| **Reviewer**: medical student or strong NEET scorer | Fast, trustworthy review of questions; recognition for contribution | Critical to accuracy. Needs an efficient console |
| **Teacher / coaching (later)** | See class progress, assign chapters | Later phase |

## Positioning

| | Typical NEET apps | PageWise |
|---|---|---|
| Core unit | Video lecture or question bank | **The NCERT page** |
| Link between book and question | Weak or absent | **Every question points to its source page** |
| Experience | Feature-heavy, noisy | **Calm, focused workspace** |
| Language | English/Hindi heavy | **English first, all NEET languages planned** |

We do not compete on video lectures, live classes or doubt-solving marketplaces.

## Principles

1. **Accuracy over volume.** A wrong answer costs marks and trust. Fewer, reviewed questions beat many unchecked ones.
2. **Page-anchored.** If a question can't point to a page, it doesn't ship.
3. **Calm, not gamified-noisy.** Light motivation (streaks, progress), never dark patterns.
4. **Laptop-first, responsive always.** Built for side-by-side reading; layouts never break on small screens.
5. **Honest copy.** No invented statistics, testimonials or claims we can't back.
6. **Grow in small steps.** Biology → more subjects; English → more languages.

## Non-goals (for now)

- Hosting or redistributing NCERT books.
- Video lessons, live classes, doubt marketplaces.
- Physics/Chemistry before Biology is excellent.
- Social feeds and chat.

## Success measures (to instrument from the first beta)

- Activation: % of new users who answer ≥5 questions in the first session.
- Retention: D7 and D30 return rate; weekly active students.
- Quality: question report rate (target: falling month on month) and reviewer approval rate.
- Reach: chapters completed per active student.
