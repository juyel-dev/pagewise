## QA scope and limits

This closeout distinguishes automated checks from visual acceptance. CI and server-rendered route responses do not prove pixel-perfect behavior at every viewport or full assistive-technology compliance. The available browser path could retrieve server-rendered HTML but did not provide an interactive browser session for click/keyboard/device testing. The Vercel sandbox API also rejected sandbox creation, so a Playwright session could not be run through that environment.

No claim of physical-device visual QA, screen-reader QA or full WCAG certification is made here. These are real limitations of the available test access, not tasks silently marked complete.

The app code, six merged UI PRs, contrast guard, CI workflow and current design documentation are complete for this UI pass. Separate product roadmap items (for example full mock-test flows, additional subject/chapter content, export/delete-account functionality and additional languages) are outside this bounded UI closeout.
